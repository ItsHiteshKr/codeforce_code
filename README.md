# Codeforces Solutions

This repository contains my solutions for Codeforces problems and contests.

## Files

- C++ source files (`.cpp`) contain the solutions.
- Compiled executables (`.exe`) are local build artifacts and are not committed.

## Build and run

From the repository directory, compile a solution with:

```powershell
g++ .\solution.cpp -o .\solution.exe
.\solution.exe
```

The `.gitignore` file excludes compiled executables and other generated build
files from Git.
